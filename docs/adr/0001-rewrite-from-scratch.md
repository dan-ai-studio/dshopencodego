# 从零重写，而不是迭代已发布的 v0.1.13

`@dan-ai-studio/dsh-opencode-go` v0.1.13 已在 `web` profile 中可用，并已实现两项能力（自有 `opencode-go` 路由、网关+在线元数据的实时目录、`x-opencode-session`）。我们仍决定在新工作区从零重写，而不是继续迭代它，因为要改的四件事都落在它的结构假设上：依赖内嵌 pi-ai 的私有副本、70KB 单文件 Host 产物、只能从 GitHub Release tarball 分发、以及"配置缺失即禁用"的目录策略。在原结构上改这四项等于重写，却要一直背着旧结构的兼容包袱。

考虑过并否决的替代方案：直接给 v0.1.13 打补丁（改动小，但无法同时满足依赖可控、可测试与自主分发）；上游改 DSH 的 `llm-pi-ai`（受 DSH 对外部 PR 的限制，且无法覆盖用量与 UI）。
