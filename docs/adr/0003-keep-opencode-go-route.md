# 路由 id 沿用 `opencode-go`

新插件是独立项目（新包名、新仓库），但 provider 键仍用 `opencode-go`。DSH 把 `provider/model` 持久化进会话与 `agent-default-model` 配置，换路由会让既有会话、默认模型与模型选择器里的历史记录全部指向一个不存在的 provider；而路由本身不是品牌，独立项目不需要靠改名来证明独立。

代价：同一 profile 内 `opencode-go` 只能由一个适配器提供，因此新插件与旧插件**互斥**，安装前必须卸载旧的。插件在注册失败时要把"路由已被占用"作为一等诊断报出来（含占用者提示），而不是静默不注册。

考虑过并否决：新路由 id 与旧插件共存（可 A/B 对比，但两边都会向同一网关发请求，且用户的既有会话与默认模型需要手工迁移）。
